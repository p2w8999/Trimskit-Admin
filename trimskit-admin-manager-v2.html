🚀 How to install the configuration

The exact folder depends on how Trimskit is installed and which path its code reads.

1
Build your list

Go to Builder, add the intended usernames, and choose permissions.

2
Export the file

Open JSON preview and click Download OPS.json. Check the usernames before using it.

3
Put it in the right folder

Single-player: use the local config folder read by the mod. Server: use the server's config folder. Follow Trimskit's actual configured path.

Important: a public website should not publish real server operator lists or secret codes. Server-side authorization must be enforced by the mod, not by trusting the website or a player's client.
